# 🛍️ Minimal E-Commerce Application

یک وب‌سایت فروشگاهی مدرن، مینیمال و کاملاً **ریسپانسیو (Responsive)** ساخته‌شده با **React** و **CSS3**.

---

## ✨ ویژگی‌های اصلی پروژه (Features)

* 📱 **طراحی ۱۰۰٪ ریسپانسیو:** چیدمان اختصاصی و بهینه‌شده برای دسکتاپ، تبلت و موبایل.
* 🍔 **منوی ناوبری هوشمند:** منوی همبرگری کشویی در حالت موبایل.
* 🔍 **جستجوی آنی (Real-Time Search):** فیلتر سریع و لحظه‌ای محصولات بر اساس عنوان و توضیحات.
* 🏷️ **دسته‌بندی اتوماتیک:** اسکرول افقی نرم برای دسته‌بندی‌ها در موبایل و فیلتر محصولات.
* 📄 **سیستم صفحه‌بندی (Pagination):** مدیریت نمایش تعداد محصولات در هر صفحه.
* 🔐 **مودال ورود و عضویت:** فرم تعاملی همراه با قابلیت دیدن/مخفی کردن رمز عبور.

---

## 🛠️ تکنولوژی‌های استفاده‌شده (Tech Stack)

* **React.js** (Hooks, State Management)
* **CSS3** (Flexbox, CSS Grid, Media Queries)
* **React Icons**
